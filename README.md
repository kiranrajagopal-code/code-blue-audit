# Code Blue Audit

Quality-team app for auditing real and mock Code Blue events.

- New audit: real or mock, date, location, initial rhythm (ASYSTOLE, PEA, VT, VF), team leader, observers
- Times (12-hour, AM/PM) with a NOW button: arrest, Code Blue initiated, CPR initiated, team arrival
- Any time can be corrected later; every correction is kept in a log (old time → new time)
- END CODE BLUE asks for the termination time and the outcome: ROSC or DEATH
- 88-point checklist in 9 phases, each item YES / NO / N/A with a remarks box
- KPIs (all, real only, mock only): arrest → Code Blue, arrest → CPR, Code Blue → team (median and % within target), checklist compliance, ROSC rate, code duration, compliance by phase, items most often marked NO
- Export PDF: the whole report (KPIs + summary of all audits + every audit in full) or a single audit
- Backup / import file to move audits between phones or combine the quality team's phones
- Works offline; audits are stored on the phone

**Android:** open the latest release on your phone and download `CodeBlueAudit.apk`.

**iPhone:** open https://kiranrajagopal-code.github.io/code-blue-audit/ in Safari → Share → Add to Home Screen.
